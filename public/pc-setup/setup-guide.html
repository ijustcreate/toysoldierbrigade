Project Lantern

Display PC setup

A practical guide to preparing a Windows 11 mini PC for one museum display.

What the setup files do

One assigned display, ready at sign-in

  • Ask for the hosted site URL, display ID, and monitor orientation.
  • Find Chrome and save the assigned display address.
  • Install the launcher, a separate Chrome profile, and desktop shortcuts.
  • Start the display when the account signs in and recover it after a crash.
Install

Prepare the mini PC

  1. Install current Google Chrome and connect the intended monitor.
  2. Extract the ZIP to a local folder.
  3. Right-click Setup-LanternDisplay.bat and choose Run as administrator.
  4. Enter the hosted site URL, display ID, and orientation.
  5. Sign in once, restart, and confirm the display opens automatically.
After installation

Keep the display available

  • The setup creates a desktop launcher and connects the site's Launch edge-to-edge TV control to it.
  • The launcher verifies Chrome really entered kiosk mode instead of reusing a normal window.
  • It creates a sign-in task and a daily 5:00 AM recovery check.
  • It prevents AC monitor, sleep, and hibernate timers from expiring.
  • For portrait displays, set Windows to Portrait and leave the Lantern mount setting at none.
Recovery and safety

What the package does not do

  • It does not change museum board content or enable remote access.
  • It does not store a Windows password or control TV power.
  • Use Task Scheduler to inspect Lantern Display - Start at sign-in and Lantern Display - 5 AM check.
  • For unattended recovery, use a dedicated, physically secured display account and follow museum IT policy.

Test automatic sign-in, wake behavior, and power-loss recovery on the delivered PC before mounting it.

Full details are included in README-PC-SETUP.md inside the setup package.
